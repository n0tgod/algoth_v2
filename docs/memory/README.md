# Память проекта: срезы истории

`CLAUDE.md` в корне — короткое **ядро**: правила, решения, состояние на
сегодня, уроки. Здесь лежит **история** — тот же текст, который до
2026-09-06 жил в ядре одним файлом (1.08 МБ, около 200 тысяч токенов на
каждую сессию), разрезанный по времени дословно. Ничего не переписано и
не выброшено: каждая запись стоит там же, в том же порядке.

## Как читать

Не подряд. Сессия читает ядро, а срез открывает по указателю ниже —
когда работа касается его предмета. Точное место внутри среза ищется
грепом: `grep -n "касс" docs/memory/*.md`.

Срезы **не дописываются**: это архив. Новое идёт в журнал
(`docs/journal/ГГГГ-ММ.md`, одна запись на значимый шаг) и в раздел
«Состояние на сегодня» ядра — переписыванием по месту, а не приписыванием.
