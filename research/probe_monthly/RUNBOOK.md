# Зонд: месячный горизонт кросс-секции

Зонд, не гипотеза: порогов и вердикта нет, решение за владельцем.
Вопрос (№2 карты направлений): сетка R-серии кончалась на 10 днях
удержания; IC возврата на 30-дневном форварде уже положителен
(+0.0324 при k=7, +0.0467 при k=14 — IDEAS.md), но КНИГА на месячном
удержании не строилась ни разу. Месячное удержание платит круг
издержек один раз за 30 дней — если спред дециля ~100 б.п./мес,
покрытие втрое-впятеро, чего не было ни у одной закрытой конструкции.

## Устройство

Пересчёт СОХРАНЁННЫХ векторов R2 (`r2_residual/out/vectors/`, живут на
VPS, в git не идут) — без прохода по хранилищу. Длинные формации и
месячный форвард собираются сцеплением 10-дневных кирпичей по
календарю, выравнивание ПО ИМЕНИ; дыра в сетке дат рвёт сцепление
(класс дефекта L2), NaN заражает имя (пропуск, не ноль).

Сетка (объявлена до прогона): формация k ∈ {14, 30, 60, 90} ×
удержание h ∈ {10, 30} = 8 ячеек; дециль; сечения непересекающиеся
(шаг h по списку дат). Главная ячейка — **k14_h30**: единственная с
внешним измерением (сцепленный IC из IDEAS), зонд добавляет к ней
книгу и издержки. Единицы — конвенция R4 (Σ|w| = 1, прибыль = ½
спреда, комиссия = оборот × 5.5, полная замена = 11 б.п.). Нуль 1 —
перестановка сигнала внутри сечения, 5 зёрен, зерно на дату числом.

## Запуск (на VPS, через очередь)

```
run research/probe_monthly/probe.py --interval 1m --tag 30d
```

Секунды счёта; публикует сам (`--no-publish` выключает). Если векторов
нет, честно падает с именем каталога — пересборка: `crosssection.py
--interval 1m` (часы, решение отдельное).

## Проверки

`test_probe.py` — 23 проверки: тождества сцепления числом (телескоп
трёх кирпичей, сумма вперёд), инвариантность к перетасовке имён между
датами, дыра рвёт цепь, NaN не ноль, калибровочная пара (AR-уровень →
IC > 0.15, случайное блуждание → ~0, нуль ~0 и воспроизводим), фразы
вердикта из чисел, сквозной прогон настоящим main(), пустой прогон
называет причины. Четыре отрицательных контроля кусаются: выравнивание
по индексу (1 падение), потерянный минус сигнала (2), нуль без
перестановки (1), фраза-литерал (2).

## Оговорки (в отчёте, не снимаются)

Кирпичи форварда считаны каждый по своей β (path_norm: 0.5–2.9 % на
k ≤ 14, на 90 больше); смещение выживших (имя живёт k+h дней);
издержки модальным тейкером; funding удержания в числах НЕТ — на 30
днях он значим (A1: медиана дифференциала 19.7 % годовых) и обязан
войти в спеку, если она будет.

## Вторая половина: funding месячной книги (`funding_cost.py`)

Те же книги (пары пересобираются кодом зонда), к каждому сечению
добавлен funding окна удержания по рядам площадки исполнения
(каталог A1, число начислений из ряда). Знак — конвенция
`funding_series`: положительная ставка — лонги платят; funding
печатается издержкой и вычитается из нетто. Нога без ряда — не ноль
(недоучтённый гросс числом, сечение с недоучётом > 10 % выпадает).
Встроенная сверка: нетто без funding обязано совпасть с артефактом
зонда, расхождение прерывает прогон.

```
run research/probe_monthly/funding_cost.py --interval 1m --tag 30d
```

`test_funding_cost.py` — 21 проверка (знак числом, окно, частота
начислений из ряда, сверка, сквозной поверх настоящего probe.main,
подделанный артефакт останавливает). Четыре отрицательных контроля
кусаются: перевёрнутый знак (5 падений), нога-в-ноль (1), снятая
сверка (2), фраза-литерал (2).

## Третья часть: три оговорки замерами (`robust.py`)

Прежде чем решать «спека или бумажная книга», закрываются три
оговорки зонда — все пересчётом тех же векторов:

1. **смещение выживших** — рука `alive` держит имя с оборванным
   хвостом кирпичей до последнего бара (так поступила бы книга на
   бирже), базовая его выбрасывает. Делистинг отличается от дыры:
   считается префикс кирпичей до первого разрыва, ряд с продолжением
   после разрыва выбрасывается в обеих руках;
2. **бюджет доказательства** — поправка Ньюи–Уэста (лаг = h−1, веса
   Бартлетта) на перекрывающихся окнах: 1300 дат вместо 44 сечений.
   Калибруется БРУТТО, а не нетто: перемешанная книга набирается
   заново каждый день и платит полный круг издержек, её нетто
   отрицательно по построению (≈ −11 б.п.), и поправка на таком ряде
   проверялась бы на величине со встроенным сдвигом;
3. **устойчивость** — те же ячейки на первой и второй половине дат
   (урок S11: градиент рассыпался на другом разрезе).

```
run research/probe_monthly/robust.py --interval 1m --tag 30d
```

`test_robust.py` — 27 проверок: NW точным числом (ряд 1,2,3,4 при
лаге 1 даёт t = 4.0 против наивного 3.873), NW кусается на AR(1) и
не кусается на белом шуме, три статуса сцепления числом, живая рука
держит выброшенное базовой, калибровка нуля, фразы из чисел,
сквозной прогон. Четыре отрицательных контроля кусаются: NW без
автоковариаций (3 падения), делистинг = дыра (1), калибровка на
нетто (1 — воспроизводит живой дефект дословно), фраза-литерал (1).
Фикстуру выживших пришлось переписать: первая роняла имена по
индексу, они в дециль не попадали, и проверка проходила бы на
сломанном коде.
