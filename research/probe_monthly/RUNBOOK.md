# Зонд: месячный горизонт кросс-секции

Зонд, не гипотеза: порогов и вердикта нет, решение за владельцем.
Вопрос (№2 карты направлений): сетка R-серии кончалась на 10 днях
удержания; IC возврата на 30-дневном форварде уже положителен
(+0.0324 при k=7, +0.0467 при k=14 — IDEAS.md), но КНИГА на месячном
удержании не строилась ни разу. Месячное удержание платит круг
издержек один раз за 30 дней — если спред дециля ~100 б.п./мес,
покрытие втрое-впятеро, чего не было ни у одной закрытой конструкции.

## Устройство

Пересчёт СОХРАНЁННЫХ векторов R2 (`r2_residual/out/vectors/`, живут на
VPS, в git не идут) — без прохода по хранилищу. Длинные формации и
месячный форвард собираются сцеплением 10-дневных кирпичей по
календарю, выравнивание ПО ИМЕНИ; дыра в сетке дат рвёт сцепление
(класс дефекта L2), NaN заражает имя (пропуск, не ноль).

Сетка (объявлена до прогона): формация k ∈ {14, 30, 60, 90} ×
удержание h ∈ {10, 30} = 8 ячеек; дециль; сечения непересекающиеся
(шаг h по списку дат). Главная ячейка — **k14_h30**: единственная с
внешним измерением (сцепленный IC из IDEAS), зонд добавляет к ней
книгу и издержки. Единицы — конвенция R4 (Σ|w| = 1, прибыль = ½
спреда, комиссия = оборот × 5.5, полная замена = 11 б.п.). Нуль 1 —
перестановка сигнала внутри сечения, 5 зёрен, зерно на дату числом.

## Запуск (на VPS, через очередь)

```
run research/probe_monthly/probe.py --interval 1m --tag 30d
```

Секунды счёта; публикует сам (`--no-publish` выключает). Если векторов
нет, честно падает с именем каталога — пересборка: `crosssection.py
--interval 1m` (часы, решение отдельное).

## Проверки

`test_probe.py` — 23 проверки: тождества сцепления числом (телескоп
трёх кирпичей, сумма вперёд), инвариантность к перетасовке имён между
датами, дыра рвёт цепь, NaN не ноль, калибровочная пара (AR-уровень →
IC > 0.15, случайное блуждание → ~0, нуль ~0 и воспроизводим), фразы
вердикта из чисел, сквозной прогон настоящим main(), пустой прогон
называет причины. Четыре отрицательных контроля кусаются: выравнивание
по индексу (1 падение), потерянный минус сигнала (2), нуль без
перестановки (1), фраза-литерал (2).

## Оговорки (в отчёте, не снимаются)

Кирпичи форварда считаны каждый по своей β (path_norm: 0.5–2.9 % на
k ≤ 14, на 90 больше); смещение выживших (имя живёт k+h дней);
издержки модальным тейкером; funding удержания в числах НЕТ — на 30
днях он значим (A1: медиана дифференциала 19.7 % годовых) и обязан
войти в спеку, если она будет.
