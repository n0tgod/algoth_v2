# Z2 — скрин по собственной записи стакана

Z1 перебрал 62 условия по минутным барам и не нашёл ничего, что платит
против круга издержек. Это ответ про свечи. Здесь перебор идёт по
величинам, которых у свечей и принтов нет **в принципе**.

## Что меряется впервые

| величина | почему её нет ни в свечах, ни в ленте |
|---|---|
| **снятие заявок** (`pull`) | изменение глубины МИНУС объяснённое сделками. Четыре замера ленты (T1–T4) видели, сколько агрессии прошло через уровень, и не видели, подставляли ли уровень заново — это и есть недостающий знаменатель |
| **ход середины без сделок** | котировка ушла, потому что сняли заявки. В ленте этому соответствует пустота |
| **выедено против показанного** | прошло ли через сторону больше, чем она показывала глубиной |
| **шторм обновлений**, растяжение лесенки, перекос глубины | состояние книги, а не факт сделки |

Пространство объявлено целиком в `probe.py`: 17 триггеров × 2 стороны ×
4 горизонта = **136 ячеек**. Отчёт печатает все.

## Машина суда — та же, что у Z1

Второй копии ядра нет: `probe.py` зовёт `z1_screen/screen.py` —
корзины длиной в горизонт, семейственная планка по Z, вердикт с
согласием медианы и СРЕДНЕГО, издержка 22 б.п. (нейтральная книга).

Три отличия, каждое вынужденное:

1. **Контроль — среднее сечения, а не медиана.** Z1 намерил, что
   превышение над медианой несёт структурный снос: +10.7 б.п. на любой
   лонг за четыре часа, потому что распределение доходностей скошено
   вправо. Медиана робастна, но она статистика, а не портфель.
   Равновзвешенная корзина сноса не имеет — и отчёт печатает снос по
   стороне отдельной таблицей: **если он не около нуля, читать
   остальное нельзя**.
2. **Момент наблюдения — позднее из двух времён снимка.** Метку `t`
   сборщик ставит ОДИН РАЗ на весь проход по символам, а проход
   занимает от 0.18 до 2.5 с; биржевая метка `ts` говорит, каким было
   состояние книги, когда его прочитали. (Правку самого сборщика —
   штамповать время внутри цикла — стоит сделать роли `fix`; замер от
   неё не зависит.)
3. **Ширина записи печатается по суткам.** Состав сборщика рос
   ступенями (25 → 518 → 559 → 725 имён), и у имени, добавленного
   вчера, нет ни собственной нормы, ни места в кросс-секции.

## Запуск на VPS

Пилот на трёх сутках — он проверяет дорогу и даёт время прогона:

```bash
cd ~/algoth_v2 && git pull
```
```bash
cd ~/algoth_v2 && mkdir -p research/z2_book/out
```
```bash
cd ~/algoth_v2 && nice -n 19 .venv/bin/python research/z2_book/probe.py --start 2026-08-20 --end 2026-08-22 --tag pilot
```

Полная запись (даты берутся из самой записи, если не указывать):

```bash
cd ~/algoth_v2 && nohup nice -n 19 .venv/bin/python research/z2_book/probe.py > research/z2_book/out/run.log 2>&1 &
```

Тесты (в песочнице): `.venv/bin/python research/z2_book/test_bookfeat2.py`
и `research/z2_book/test_probe.py` — шесть и пять блоков; отрицательные
контроли (момент наблюдения по нашей метке, снятие без учёта сделок,
нормы по текущим суткам) обязаны их ронять.

## Как читать

- **Снос по стороне не около нуля** — дальше не читать: контроль
  считается не тем, чем задумано.
- **Ячейка выше планки И медиана со средним согласны** — повод строить
  гипотезу с объявленными порогами. Не торговать: у ячейки нет ни
  стопа, ни цели, ни размера, ни конкуренции за слоты.
- **«короткая волатильность»** — медиана выше круга, среднее ниже:
  выигрывает часто и по мелочи, отдаёт разом. Эта форма убила гипотезы
  3 и 4.
- **Ни одной ячейки** — в объявленном пространстве закономерностей нет,
  и это настоящий ответ.

## Чего v1 не покрывает

Снятие считается по ПОЛОСЕ ±0.25 %, привязанной к середине, а середина
движется: часть «снятия» на резком ходе есть смещение полосы, а не уход
заявок. Честная версия требует разбора лесенки по ценам уровней (якорь
абсолютный, а не относительный) и стоит на порядок дороже — это
следующий шаг. Туда же: время жизни уровня, смерть крупного уровня без
единой сделки, нотионал снесённой книги.
