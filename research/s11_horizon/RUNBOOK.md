# S11 — зонд горизонта сигнала ситуационных книг

Вопрос: какая была бы статистика книги на 24-часовом сигнале вместо
4-часового, и на каком горизонте сигнала вообще лучше торговать.
Сетка объявлена в коде: 4 / 5 / 6 / 8 / 12 / 24 часа, обе руки, обе
книги (гейт RR ≥ 2 и потолок RR ≤ 1.5).

Устройство: одна честная разбивка по времени — модели каждого
горизонта обучаются на первых 60 % часов записи (с отступом на сам
горизонт, правило M2 `s + h < T`), реплей книги идёт по хвосту,
которого обучение не видело. Исходы — по минутным барам записи
сборщика, ядром турнира политик.

Запуск на VPS (30–60 минут, приоритет понижен — рядом живой сбор):

```bash
cd ~/algoth_v2 && git pull
cd ~/algoth_v2 && setsid nohup nice -n 19 .venv/bin/python research/s11_horizon/horizon_probe.py >> research/s11_horizon/out/run.log 2>&1 &
```

Ход прогона (печатает каждое обучение):

```bash
cd ~/algoth_v2 && tail -n 8 research/s11_horizon/out/run.log
```

Отчёт публикуется прогоном сам: `out/S11-horizon-1m.md` уедет в git.
Смоук/повтор с другой разбивкой: `--split 0.5 --tag smoke50`
(смоук-тег в git не идёт).

Тесты: `python3 research/s11_horizon/test_horizon.py` (песочница).
