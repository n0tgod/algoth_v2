# Зонд: набор на цене, фон из хранилища A2

Символов ленты 16, окно 2025-03-03 … 2025-03-09. События — из ленты Bybit по секундной сетке; **форвард и фон — из хранилища A2** (1m, 348 символов), и оба из одного источника: иначе базис между площадками вошёл бы в разность как эдж.

Вход — открытие первого бара, начинающегося ПОСЛЕ события, то есть первая цена, по которой сделка возможна. В T1 вход брался по закрытию секунды обнаружения — по цене, которой уже нет.

## Как читать

**«Отход»** — насколько цена к концу окна ушла от уровня набора. Большая величина означает, что войти по уровню уже нельзя, и замер описывает другую сделку.

**Превышение ниже круга издержек** — сигнал есть, торговать нечем. Так закрылись каскады (11.4 б.п. против 11.7) и поглощение без уровня (−0.2 б.п. при круге 11).

**«В пользу» есть потолок сверху** — лучший возможный выход внутри горизонта, при идеальном знании будущего. Меньше круга — ячейка мертва по арифметике при любом сигнале.

**Отношение «в пользу / против» около единицы** — размах симметричен, и ставить ограничитель некуда. Асимметрия одного знака у ОБЕИХ сторон означает снос рынка за период, а не свойство события: в T1 так и было.
