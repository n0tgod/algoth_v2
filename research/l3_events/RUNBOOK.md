# L3 — события, эпизоды и контроли. Инструкция для VPS

Единственный дорогой проход гипотезы 5. Отсюда выходят векторы, из
которых L4 и L5 считаются пересчётом за секунды.

**Что он может решить.** Критерий немедленной остановки §9.1, и прежде
всего контроль 2 — события без условия на открытый интерес. Если
превышение то же самое, механизм принудительного закрытия оказывается
украшением, а гипотеза сводится к «покупай падение». Предпросмотр на
разведочной выборке показал, что это наиболее вероятный исход.

---

## 0. Что должно быть на месте

```bash
cd ~/algoth_v2 && git pull

ls research/asset_groups/out/daily_liquidity_1m.csv.gz

.venv/bin/python research/l3_events/test_l3.py
```

Тесты обязаны пройти все двадцать.

## 1. Пилот

```bash
cd ~/algoth_v2 && .venv/bin/python research/l3_events/run.py --limit 40 \
  --start 2025-01-01 --end 2025-06-30
```

Минуты. Смотреть надо не на числа — выборка не та, — а на то, что
конвейер доходит до конца и печатает обе руки и блок вердикта.

## 2. Полный прогон

```bash
cd ~/algoth_v2 && nohup .venv/bin/python research/l3_events/run.py \
  > research/l3_events/out/l3.log 2>&1 &
```

| Что | Оценка |
|---|---|
| Символов | ≈ 618, вердикт по 606 подтверждающим |
| Моментов сетки | 270 720 (940 суток × 288) |
| Память | ≈ 0.7 ГБ на матрицу цен плюс месячные срезы |
| Время | 30–60 минут |

Следить: `tail -f research/l3_events/out/l3.log`. Прогон печатает
прогресс по месяцам при загрузке цен и по каждым пятидесяти символам
при отборе — молчания дольше минуты быть не должно.

## 3. Публикация

```bash
cd ~/algoth_v2 && tools/publish.sh "L3: события, эпизоды и контроли"
```

Ряды и векторы в git не идут, отчёт идёт.

## Что читать в отчёте

**Сначала блок «Критерий немедленной остановки §9.1»** — три условия,
каждое числом. Сработало хотя бы одно — работа прекращается до L5, и
это законный исход, а не неудача прогона.

**Потом критерий 8** — во сколько раз условие на интерес улучшает
превышение против контроля 2. Порог 1.5×.

**Разведочная часть — справка, а не результат.** На этих двенадцати
активах выбраны пороги; вердикт по ним был бы выбором, выданным за
предсказание.
