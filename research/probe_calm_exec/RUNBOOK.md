# Зонд: пассивный вход в спокойном рынке

Зонд, не гипотеза: порогов и вердикта нет, решение по таблице за
владельцем. Вопрос: D1 намерил, что в СТРЕССЕ пассивная заявка — смена
выборки со сменой знака (отбор −54.7 б.п.). Живые книги входят в
обычные часы; если там отбор мал, круг издержек ноги падает с 11 до
~4 б.п., и арифметика всех будущих гипотез меняется.

## Мера

В начале каждого часа по каждому имени среза: тейкерский вход против
двух лимиток (на лучшей своей стороны, на середине), обе стороны. Все
руки оцениваются в ОДНОЙ точке через час; лимитка, не исполнившаяся за
`T ∈ {60, 300, 900}` с, доисполняется тейкером — рука «мейкер» есть
стратегия «поставь, не вышло — бей рынок». Выгода = value(пассив) −
value(тейкер), б.п. нотионала ноги ($300 — нога ситуационной книги).

Модель очереди — та же, что в D1 (`d1_seconds/passive.py`, `fill_at`):
исполнение по факту прошедшей сквозь уровень встречной агрессии, не по
касанию; отмены не видны — работает против пассивной руки. Сторона
продажи добавлена параметром `side` (умолчание — прежняя покупка, счёт
D1 бит в бит, под тестом).

Ось состояния — ход середины за час до заявки в единицах причинной σ
(по прошлым СУТКАМ символа, минимум 48 часовых доходностей). Полоса
«спокойно» (|z| < 0.25) — предмет зонда; главная ячейка объявлена до
прогона: «спокойно», T = 60 с, рука «на лучшей», обе стороны, счёт по
эпизодам (час — один голос).

## Запуск

Смоук (минуты):

```
run research/probe_calm_exec/probe.py --days 2 --take 6 --tag smoke --no-publish
```

Полный прогон (оценку времени даёт смоук; публикует сам):

```
run research/probe_calm_exec/probe.py --tag 1s
```

Артефакты: `out/CALM-exec-<тег>.json` и `.md`. Смоук в git не идёт
(`--no-publish`, свой тег).

## Проверки

`test_probe.py` — 20 проверок: калибровочная пара числом (выгода =
спред + 3.5 при исполнении; РОВНО ноль на плоской цене без исполнения),
зеркало стороны, очередь продажи с аска, дыра — пропуск, причинность σ,
фильтр не-крипто, сквозной прогон настоящим `main()`. Четыре
отрицательных контроля прогнаны и кусаются: перепутанная сторона (3
падения), снятое доисполнение тейкером (4), фраза-литерал (2), σ из
текущих суток (2).
