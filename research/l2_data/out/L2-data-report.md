## 3. Порог по размеру инструмента

Спека 06 §7.3 требует открытого интереса не ниже **$5,000,000** на момент события: у актива с интересом в $200 тыс. падение на 3 % есть закрытие одной позиции, а не каскад. Здесь порог применён к медиане по всей истории — это оценка сверху для L3, где он проверяется на каждую дату.

| Мера | Значение |
|---|---|
| Символов с измеримым интересом | 614 |
| Из них выше $5,000,000 | **256** (42%) |
| Медиана медианного интереса | $4,032,347 |
| 10-й процентиль | $1,784,259 |

## 4. Подтверждающая часть

Вердикт раздела 9 спеки выносится только на ней; двенадцать активов зонда L1 в неё не входят никогда.

| Часть | Символов |
|---|---|
| Разведочная (зонд L1) | 12 |
| Подтверждающая, всего | **606** |
| Подтверждающая, выше порога размера | **244** |

Разведочная часть дала 168 эпизодов на двенадцати активах. Подтверждающая шире по числу инструментов в 20.3 раза — это и есть рычаг измеримости, ради которого гипотеза 5 меняет знаменатель доказательства (§2 спеки). Во сколько раз вырастет число эпизодов, отсюда не следует: события рынка одновременны, и слипание в эпизоды (§7.5) съест часть прироста. Величину даст L3, предполагать её здесь нельзя.

## 5. Чего в этом отчёте нет

Ни одного числа о доходности. L2 — только данные; отбор событий, контроли и нули идут в L3, вердикт — в L5.
