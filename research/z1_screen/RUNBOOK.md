# Z1 — скрин закономерностей по записанным данным

Просьба владельца (2026-08-24): не разбирать наши проверенные гипотезы,
а вывести своё из самих данных — «возможно, ты можешь сам найти
какие-то закономерности поведения».

Скрин — машина, которая перебирает **объявленные условия** по нашим
записям и меряет, предсказывает ли условие ход цены **сверх
одновременной кросс-секции**. Это не гипотеза и не стратегия: у ячейки
нет ни стопа, ни цели, ни размера, ни конкуренции за слоты.

## Почему перебор здесь законен

Перебор сотен ячеек — ровно та ошибка, что убила R5 (при 96 испытаниях
лучшая пустышка давала Sharpe 1.19). Отличий три:

1. пространство объявлено целиком до прогона — 62 условия × 4 горизонта
   = **248 ячеек**, таблица лежит в `screen.py`, отчёт печатает ВСЕ;
2. планка **семейственная**: 95-й процентиль МАКСИМУМА превышения по
   всем ячейкам под нулём, который переставляет, какой символ сработал,
   оставляя минуту на месте;
3. мера — превышение над одновременной кросс-секцией, а не над нулём:
   проект трижды находил, что «эффект» принадлежал рынку.

## Что перебирается

| группа | о чём |
|---|---|
| ход | движение в собственных единицах: реверсия против продолжения |
| объём, агрессия | всплеск оборота, крупные сделки, доля агрессивных покупок |
| фон | тот же ход при спокойном и при паникующем рынке |
| диапазон | пробой вчерашних краёв, всплеск после покоя |
| интерес | **четыре квадранта «цена × открытый интерес»** |
| тишина | возобновление торгов после перерыва |
| угасание | оборот в нижнем дециле собственной истории |
| листинг | первые тридцать суток жизни инструмента |

Главное новое — квадранты. L3 проверил РОВНО ОДИН из четырёх (падение
при падающем интересе, 0.51× против простого падения). Квадрант
«падение при РАСТУЩЕМ интересе» — новые шорты входят в падение — не
проверялся ни разу, а это ровно то состояние, из которого рождались
сквизы, убившие гипотезы 3 и 4.

Доля агрессивных покупок берётся из `taker_buy_quote_volume` — колонка
лежит в хранилище с 2020 года и в проекте не использовалась НИ РАЗУ:
агрессор мерился только по ленте Bybit, на 16 символах за неделю.

## Что нашла состязательная проверка замысла (и что исправлено)

Флот критиков читал код до полного прогона и нашёл **три заглядывания
в будущее в самом скрине** — все три невидимы в отчёте, потому что
прогон от них не падает и число событий не меняется:

1. **лаг открытого интереса стоял В ШАГАХ.** Слой L3 сдвигает ряд на
   один шаг, и на его пятиминутной сетке это ровно те пять минут,
   которые требует замер задержки публикации. На нашей МИНУТНОЙ сетке
   тот же шаг — одна минута, то есть четыре минуты будущего в каждой
   ячейке с интересом. Лаг считается временем;
2. **объёмные окна включали текущий бар**, объём которого известен
   только в его конце. Окна кончаются на прошлом баре;
3. **ранг оборота считался против всего загруженного окна**, включая
   будущие дни месяца. Ранг берётся по строго прошлым суткам.

Ещё две правки меняют вердикт, а не украшают его:

- **издержка вердикта — 22 б.п., а не 11.** Превышение над
  кросс-секцией есть PnL рыночно-НЕЙТРАЛЬНОЙ книги (нога плюс хедж об
  сечение), значит платятся две ноги. Сравнивать превышение с одним
  кругом — числитель одной сделки против знаменателя другой, ровно та
  ошибка единиц, что R4 нашла в спеке 03. Рядом стоит «сырая медиана»
  — та же сделка без хеджа, её круг 11;
- **β-утечка** печатается числом: кросс-секция снимает уровень рынка,
  но не экспозицию, и у события с крупным ходом бета выше единицы.

## Защиты, каждая закреплена тестом

- **вход по открытию СЛЕДУЮЩЕГО бара**: вход по бару решения есть
  подарок себе (урок зонда возврата);
- **единица наблюдения — корзина длиной в горизонт**, а не событие и не
  «эпизод по разрыву»: перекрывающиеся форварды не независимы, а
  слипание по разрыву на частом сигнале вырождается — первый прогон
  теста схлопнул 200 событий в ДВА эпизода;
- **своё событие исключено из своего же контроля**, узкое сечение
  (< 50 имён) — пропуск, а не число;
- **доля универсума в событии печатается числом**: условие, которое
  срабатывает у всего рынка разом, делает контроль бессмысленным, и это
  обязано быть видно (так умерла ячейка 2 % в зонде возврата);
- **бар без сделок — пропуск**, единицы символа берутся за ПРОШЛЫЕ
  сутки, нулевой шум становится пропуском, а пол шума берётся из
  САМОГО сечения (урок S1: обратная σ без пола отдавала одному имени
  92.7 % книги);
- **вердикт требует согласия медианы и СРЕДНЕГО.** Пилот показал,
  зачем: семейство «шорт после роста» дало медиану +41 б.п. при
  среднем −17 и доле побед 0.79 — форма короткой волатильности,
  убившая гипотезы 3 и 4. Отчёт по одной медиане предъявил бы её как
  находку;
- **планка считается по Z относительно собственного нуля ячейки** и
  только по ячейкам с корзинами ≥ 50: в пилоте ячейка на 34 событиях
  дала медиану +669 б.п. и одна подняла планку всем до +55.

## Запуск на VPS

Сначала пилот на квартале — он проверяет дорогу и даёт время прогона:

```bash
cd ~/algoth_v2 && git pull
```
```bash
cd ~/algoth_v2 && mkdir -p research/z1_screen/out
```
```bash
cd ~/algoth_v2 && nice -n 19 .venv/bin/python research/z1_screen/screen.py --start 2026-04-01 --end 2026-06-30 --tag pilot --no-publish
```

Если пилот прошёл и время терпимо — полное окно (оно же окно рядов
открытого интереса):

```bash
cd ~/algoth_v2 && nohup nice -n 19 .venv/bin/python research/z1_screen/screen.py > research/z1_screen/out/run.log 2>&1 &
```

Отчёт публикуется прогоном сам: `out/Z1-screen-1m.md`.

Тесты (в песочнице): `.venv/bin/python research/z1_screen/test_screen.py`
— десять блоков; отрицательные контроли (вход по бару решения, своё
событие в своём контроле, слипание вместо корзин) обязаны ронять их.

## Как читать результат

- **ячейка выше планки И выше круга издержек** — есть повод строить
  гипотезу с объявленными порогами и своим нулём. Не торговать сразу:
  скрин не проверяет ни исполнение, ни конкуренцию за слоты;
- **ни одна ячейка не выше планки** — в объявленном пространстве
  закономерностей нет, и это настоящий ответ, а не отсутствие ответа;
- **высокая доля универсума** у ячейки — она поймала состояние рынка, а
  не поведение инструмента; читать её нельзя;
- **много событий, мало корзин** — наблюдений меньше, чем кажется.

## Чего скрин не покрывает (v1)

Funding как условие (уровень ставки, скачок, смена режима начисления
площадкой) — данные есть, загрузчик в скрин не заведён. Импульсная
разгрузка интереса одной ступенью, очередь и восполнение стакана из
собственной записи B1 — следующий слой, там своя цена счёта.
