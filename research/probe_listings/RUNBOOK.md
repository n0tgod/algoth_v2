# Зонд: первые дни жизни инструмента (листинги)

Зонд, не гипотеза: порогов и вердикта нет, решение за владельцем.
Вопрос (№3 карты направлений): правило «365 дней истории» вырезало
первые дни жизни каждого инструмента из всех семи гипотез — стенд туда
не смотрел никогда. Событий 847 с 2022 года: измеримость покупается
числом событий, не годами.

## Мера

Событие — `listed` из справочника универсума (первый день ряда
Binance; начало после дыры листингом не является). Вход по ЗАКРЫТИЮ
дня `listed + d`, d ∈ {1, 3, 7}; горизонт h ∈ {7, 30, 90} — 9 ячеек,
главная **d1_h30** (самый ранний реализуемый вход, месячный горизонт).
Величина — доходность новичка минус равновзвешенное среднее зрелых
(возраст ≥ 365) за то же окно. Свод по событиям И по когортам (месяц
листинга — один голос: листинги идут волнами). Делистнутый внутри
горизонта считается до последнего бара (вырезать его — вырезать худшие
исходы); край данных и дыра входа — пропуск, не ноль. Не-крипто вон.

Нуль — псевдо-события на зрелых именах той же численности, 5 зёрен:
ловит дефект конвейера. Рядом funding новичков: суточная ставка в
окнах [0, 7) и [7, 30) от первого начисления ряда Bybit, квартили и
доля отрицательных.

## Запуск (на VPS: хранилище A2 + ряды funding)

```
run research/probe_listings/probe.py --tag 1d
```

Один запрос дневных закрытий по хранилищу (минуты), дальше секунды.
Публикует сам; `--no-publish` выключает.

## Проверки

`test_probe.py` — 23 проверки: калибровочная пара (подсаженный дрейф
−30 б.п./день найден, без дрейфа ноль, нуль ≈ 0), задержка не видит
памп дня листинга, база сверена ручным счётом и не пускает молодого
грязного соседа, делистинг до последнего бара, край/дыра/тонкая база —
пропуски, когорта один голос, funding числом, отчёт из настоящего
run(). Четыре отрицательных контроля кусаются: потерянная задержка (3
падения), снятый порог зрелости базы (1), выброшенный делистинг (1),
фраза-литерал (1). Первый контроль на порог зрелости НЕ кусался — ни
одна фикстура не держала живого грязного соседа в окне события; тест
дописан, урок «защита, которой молча нет».
