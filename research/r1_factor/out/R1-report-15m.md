**Спека:** 03, этап R1, условия §8.1  
**Окон:** 48, измерено 48  
**Шаг теста:** 1h, сравнение с 4h, 1d  
**Разрешение хранилища:** 15m

## 1. П1 — волна действительно является волной

Мера — доля дисперсии доходностей актива, объяснённая равновзвешенной волной универсума, медиана по активам внутри окна и медиана по окнам.

- медиана по окнам — **65.3 %** при пороге 40 %
- разброс по окнам: минимум 33.6 %, максимум 79.2 %
- квантили по окнам: 5-й 52.0 %, 25-й 58.4 %, 75-й 68.7 %, 95-й 76.9 %
- в агрегате (взвешенно по дисперсии) — 57.1 %
- окон ниже порога: **1** из 48

Агрегат ниже медианы закономерно: он взвешен дисперсией, а самые волатильные активы — это и есть самые «свои», хуже всего объяснимые общей волной. Обе величины докладываются, чтобы выбор меры не менял вывод.

**Окна, не прошедшие порог поодиночке:**

| Окно | Активов | Доля дисперсии |
|---|---|---|
| 2026-05-11 | 334 | 33.6 % |

**Тренд.** Первые двенадцать окон дают медиану 68.2 %, последние двенадцать — 63.6 %. Волна не разрушается, но слабеет по мере расширения универсума: в 2022 отбору удовлетворяют 20 активов, преимущественно мажоры, ходящие вместе; к 2026-05-11 их 334, и хвост альтов имеет собственную жизнь. Это существенно для R2: хедж об волну слабее там, где данных больше всего.

## 2. П2 — эффект Эппса на доходностях

A4 закрыла вопрос для β **на уровнях цен** (β(1m)/β(1h) = 0.999 / 1.000 / 1.001) и оставила оговорку: Эппс бьёт по оценкам на доходностях. Эта спека считает по доходностям, поэтому проверка сделана заново.

| Шаг | β(шаг)/β(1h), медиана по окнам | Отклонение от 1 | Окон |
|---|---|---|---|
| 4h | 1.0001 | 0.01 % | 48 |
| 1d | 0.9992 | 0.08 % | 48 |

Наибольшее отклонение — 0.08 % при допуске 15 %. **Систематического занижения β на мелком шаге нет**, то есть хедж на 1h не недооценивает экспозицию и книга остаётся нейтральной. Оговорка A4 снята и для доходностей.

## 3. Проверки корректности

**Средняя β по сечению обязана выходить около единицы** — каждый актив входит в волну с весом 1/n, и это следует из построения, а не из свойств рынка. Отклонение означало бы ошибку расчёта.

- медиана β по окнам: 1.015, диапазон 0.954–1.042

**Актив исключён из собственной волны.** При трёхстах активах собственный вес 1/300 и роли не играет, но в ранних окнах их двадцать. Размер смещения измерен, а не объявлен малым:

- β с включением себя / β без: медиана по окнам 1.0034, максимум 1.0192

То есть на живых данных поправка оказалась мелкой. Узнать это можно было только измерив: на синтетике из двадцати активов актив, не связанный с рынком, при включении себя получает β больше 0.5.

## 4. Состав окон

- ликвидных активов на окно: медиана 177
- оценено β: медиана 177, минимум 20
- из них с меткой сектора A3: медиана 174

Волна строится по **всему** ликвидному универсуму, а не только по размеченной его части: A4 требовала метку, потому что без неё не из чего составить пару, а волна есть свойство рынка целиком.

## 5. Что дальше

Посылка выполнена — переход к R2 (возврат остатка вне выборки, критерии §8.3 п. 1–3). Открытым в R1 остаётся вопрос, поднятый самими данными: доля объяснённой дисперсии падает к концу истории, и последние окна — самые слабые. Если в R2 сигнал окажется сосредоточен там же, это придётся объяснять, а не списывать.
