# M2 — прогон на VPS

Два шага, строго по очереди: M2 отказывается работать на матрице без
признака `age` (он добавлен в M1 после первой сборки, до первого
прогона модели).

```bash
cd ~/algoth_v2
git pull

# 1. Пересобрать матрицу (~2 минуты; появится признак age)
tools/run.sh "M1: матрица признаков (с возрастом листинга)" \
  research/m1_features/build.py

# дождаться конца по журналу:
tail -f research/m1_features/out/build.log
# должно кончиться публикацией; после этого —

# 2. Полный M2 (много часов, большая часть — ось «сутки»;
#    цена и проекция печатаются после первого же обучения)
tools/run.sh "M2: walk-forward, модель против одиночного признака" \
  research/m2_walkforward/run.py
tail -f research/m2_walkforward/out/run.log
```

Порядок внутри прогона: нуль 3 (обучение на перемешанных форвардах,
10 зёрен × 2 горизонта) считается ПЕРВЫМ; если он даёт |IC| > 0.01,
конвейер течёт, сетка не считается и отчёт публикуется с этим
вердиктом. Дальше 8 ячеек от дешёвой оси к дорогой: статическая →
месяц → неделя → сутки.

Связь можно рвать сразу после запуска — `run.sh` отвязан от ssh и
публикует отчёт сам. Прогон молчит не дольше минуты: каждое 25-е
обучение печатает счётчик и среднюю цену.

Смоук (не для вердикта, в git не идёт):

```bash
.venv/bin/python research/m2_walkforward/run.py --tag smoke \
  --cells h1_static,h5_static --null-seeds 1 --trees 25
```
