# algoth v2 — парный трейдинг на крипто-перпах

Исследовательский стенд и торговый движок для стат-арбитража на бессрочных фьючерсах.

**Текущая фаза: A — исследование.** Задача этой фазы одна: честно ответить, существует ли устойчивый эдж, до того как написана хоть строчка торгового бота. Отрицательный ответ — такой же полноценный результат, как положительный, и стоит он на порядок дешевле.

---

## Что это

Система торгует не направление рынка, а **отношения между активами**: покупает один инструмент, продаёт другой, зарабатывает на возврате спреда к среднему. Базовая единица — не сделка, а **позиция** из двух ног, которая открывается и закрывается только целиком.

Проект не является продолжением первой версии платформы. Из неё переиспользуются идеи, отдельные компоненты (таблица maintenance margin Binance, SQL взвешенных корзин) и — главное — понимание, почему она не сработала.

## Порядок фаз

| Фаза | Капитал | Что доказывает |
|---|---|---|
| **A. Исследование** | $0 | Есть ли эдж. Бэктест, walk-forward, статистическая валидация |
| B. Paper trading | $0 | Инженерная корректность на живых данных |
| C. Живой микро | $1–2k | Реальные исполнения, проскальзывание, funding, нештатные ситуации |
| D. Масштаб | $10–20k | Здесь живые результаты становятся статистически осмысленными |
| E. Упаковка | — | Продукт с реальным треком за спиной |

Решение «работает или нет» принимается на фазе A. Если она закрывается отрицательно, фаз B–D не будет.

## Площадки

| Роль | Площадка |
|---|---|
| Исполнение | Bybit |
| Источник длинной истории | Binance (только данные, торговля недоступна) |

Отношение между активами — свойство активов, поэтому коинтеграцию законно оценивать на длинной истории Binance. Экономика сделки — свойство площадки, поэтому комиссии, ставки funding, листинги и делистинги берутся строго с Bybit.

Вся специфика биржи живёт за узким адаптером: выбор площадки должен оставаться обратимым.

## Исследования

### `research/a0_venue_inventory` — инвентаризация площадок ✅

Фактические размеры универсумов, глубина публичной истории, доступность данных. Отчёт: [`out/A0-report.md`](research/a0_venue_inventory/out/A0-report.md).

Ключевые результаты:

- рабочий универсум — **721 базовый актив** на пересечении Bybit и Binance
- глубина истории: 4+ года у 99 активов, 3+ года у 174, 2+ года у 268
- **30.5 % USDT-перпов Bybit уже делистнуты**, медианный срок жизни 436 дней, темп растёт

Последний пункт продиктовал требование определять универсум **на момент времени**: отбор активов «у которых на сегодня есть N лет истории» — это отбор выживших.

Запуск:

```bash
cd research/a0_venue_inventory
python3 inventory.py      # сбор, только стандартная библиотека, кэш на диске
python3 report.py         # отчёт из собранных данных
```

Сбор данных Bybit требует запуска оттуда, где доступен `api.bybit.com`.
