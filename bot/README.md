# bot — исполнительное ядро (спека 09)

Rust-часть бота: журнал, позиции, риск, исполнение. Стратегии здесь нет
ни строки — решения приходят из часового цикла модели.

Сделано (этап E1): журнал событий с суточной ротацией и честным
чтением, состояние счёта как чистая функция от журнала, команда показа.
Сделано (этап E2, счётная часть): чтение выборов и разборов модели,
бумажное исполнение по записанным лесенкам, размер и касса как у
Python-счёта, выключатель KILL; чётность закреплена фикстурой,
порождённой самим Python-счётом (`tests/gen_parity.py`).

Сторож исполнения — двумя независимыми половинами: `bot check` смотрит
инварианты внутри журнала (касса сходится с историей, плечо не выше 1×,
застрявшие позиции, тишина решений), `sverka.py` сравнивает каждую
сделку бота с Python-счётом до цента — состав в обе стороны, размеры,
цены исполнения дословно, деньги, баланс.

```
cargo test                       # все проверки E1–E2 и сторожа
cargo run -- state <dir>         # состояние из каталога журнала
cargo run -- check <dir>         # инварианты; выход 1 при нарушении
cargo run -- shadow --s8 research/s8_loop/out/model_pretest \
    --journal bot/out/shadow --fees research/a1_universe/out/fees.json
python3 bot/sverka.py --s8 … --journal …   # сверка с Python-счётом
```

Сборка и тесты идут в песочнице разработки; на VPS код попадает уже
проверенным.

## Развёртывание на VPS (один раз)

```
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
. "$HOME/.cargo/env"
cd ~/algoth_v2 && git pull && tools/run_bot.sh
```

Дальше ядро живёт само: `tools/run_bot.sh` собирает и запускает демона
(`bot run` — проход тени раз в минуту, инварианты каждый такт, сверка
раз в час), cron-сторож `watchdog_book.sh` поднимает умершее и
перезапускает повисшее по свежести `status.json`. Панель ядра — на
странице наблюдения. Аварийный стоп: `touch bot/out/shadow/KILL`
(снять — удалить файл).

Дальше по спеке: E2 — бумажный адаптер и тень Python-счёта, E3 —
передача счёта после семи чистых дней сверки, E4 — живой адаптер
(фаза C, отдельное решение владельца).
