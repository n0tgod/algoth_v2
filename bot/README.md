# bot — исполнительное ядро (спека 09)

Rust-часть бота: журнал, позиции, риск, исполнение. Стратегии здесь нет
ни строки — решения приходят из часового цикла модели.

Сделано (этап E1): журнал событий с суточной ротацией и честным
чтением, состояние счёта как чистая функция от журнала, команда показа.
Сделано (этап E2, счётная часть): чтение выборов и разборов модели,
бумажное исполнение по записанным лесенкам, размер и касса как у
Python-счёта, выключатель KILL; чётность закреплена фикстурой,
порождённой самим Python-счётом (`tests/gen_parity.py`).

```
cargo test                       # все проверки E1–E2
cargo run -- state <dir>         # состояние из каталога журнала
cargo run -- shadow --s8 research/s8_loop/out/model_pretest \
    --journal bot/out/shadow --fees research/a1_universe/out/fees.json
```

Сборка и тесты идут в песочнице разработки; на VPS код попадает уже
проверенным, там один раз ставится rustup и собирается release.

Дальше по спеке: E2 — бумажный адаптер и тень Python-счёта, E3 —
передача счёта после семи чистых дней сверки, E4 — живой адаптер
(фаза C, отдельное решение владельца).
